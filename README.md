# CPU5006-20-S1_Rules_based_AI
Repository for S1 student submission for a rule based AI solution


## Rule Based AI Credit Risk Checker 

A rule based AI that uses Rules and forward chaining to decide if someone is a good or bad risk with credit
A rule based AI that uses Rules and forward chaining to predict if a given loan would be a "bad" credit risk.

## the files used
- Credit_Risk_Rules.py
- test_data.csv
- training_data.csv
- requirements.txt

## How to run
- Keep all the files in the folder and run the program

```bash
pip install -r requirements.txt
python Credit_Risk_Rules.py
``` 

the program uses `random.seed(42)` to pseudo-randomise the data so the results stay the same every time 

## Results 
- the results achieved was a 70% accuracy compared with a baseline of 49% of 336 entries
